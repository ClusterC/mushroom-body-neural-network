# Project Rules

## Language & Communication Constraints
1. **Thai Language Requirement**: Always respond, explain, report, and communicate with the user in **Thai**.
2. **Professional Tone & Style**:
   - Omit polite ending particles (`ครับ`, `ค่ะ`, `นะคะ`).
   - Omit hesitation/uncertainty words (`อาจจะ`, `น่าจะ`, `จริงๆแล้ว`).
   - Omit redundant greeting/filler phrases (`ได้เลยครับ`, `แน่นอน`).
   - Maintain complete grammatical structure, concise, clear, and professional tone.

## Documentation & Project Overview Synchronization
1. **Mandatory Documentation Update**: ทุกครั้งที่มีการพัฒนา เพิ่มเติม หรือปรับโครงสร้างสถาปัตยกรรม ต้องทำการอัปเดตเอกสารหลักของโปรเจกต์ ([README.md](file:///e:/My%20DriveV2/project/Python/Mushroom body/README.md)) ให้สะท้อนภาพรวมและสถานะปัจจุบันเสมอ
2. **Comprehensive Architecture Context**: เอกสารต้องระบุความสัมพันธ์ของทุกโมดูล,และขั้นตอนการทำงาน เพื่อให้ทั้งผู้พัฒนาและ AI เข้าใจภาพรวมของทั้งโปรเจกต์ได้อย่างสมบูรณ์
